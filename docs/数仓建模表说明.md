# 数仓 DWD 层表结构（9 张）

> DWD 为清洗后的明细层，供后续维度/事实建模使用。8 张有用，1 张（dwd_log）低价值。
> `*_dt` 后缀为标准时间列（`from_unixtime` 转出的 `yyyy-MM-dd HH:mm:ss` 字符串）。
